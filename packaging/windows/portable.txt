This is a portable copy of Heronite.

While this file sits next to heronite.exe, Heronite keeps everything in
this folder: your library and settings in "data" and "config", thumbnails and
other throwaway files in "cache". It does not use your user folders and
registers nothing in Windows on its own (no heronite:// links), so you can
carry the folder to another computer or delete it to remove Heronite. Updates
from inside the app replace the program in this folder.

Delete this file to make this copy use your user folders instead, like an
installed Heronite: %APPDATA%\heronite and %LOCALAPPDATA%\heronite. The
"data", "config" and "cache" folders here are then no longer used (move their
contents there by hand if you want to keep them).

Games are installed where you choose in Heronite's settings, not in this
folder unless you pick it.
